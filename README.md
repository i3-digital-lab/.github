## Курс «От скрипта до сервиса»

Шесть занятий, один сквозной проект — **docstore**, хранилище текстовых документов. Начинаем со скрипта на Python и заканчиваем сервисом, который запускается одной командой.

| № | Тема | Что появляется в проекте |
| --- | --- | --- |
| 1 | Python для работы с данными | функции загрузки, проверки и сохранения документов |
| 2 | Git | проект в репозитории, ветки и pull request |
| 3 | SQL | учебная база, запросы, таблицы и ключи |
| 4 | ORM | модели SQLAlchemy и работа с базой из Python |
| 5 | FastAPI | API из пяти эндпоинтов и тесты |
| 6 | Docker и PostgreSQL | сервис и база в контейнерах |

Учебная база для занятия 3 — [course-sql](https://github.com/i3-digital-lab/course-sql).

## Правила для учеников

**Репозиторий**

- Один проект на весь курс: `docstore-фамилия`, латиницей, например `docstore-ivanov`.
- Владелец — организация `i3-digital-lab`, видимость — **Private**.
- Создаём пустым: без README, .gitignore и лицензии — их добавите сами.

**Коммиты**

- Закончили шаг задания — коммит.
- Сообщение отвечает на вопрос «что делает этот коммит?»: `feat: добавить поиск по слову`, а не `fix` или `правки`.
- Перед каждым коммитом — `git status`.
- В конце занятия — `git push`. Работа проверяется по репозиторию.

**Безопасность**

- Пароли, токены и файл `.env` в репозиторий не попадают никогда.
- Данные и локальные базы — в `.gitignore`.
